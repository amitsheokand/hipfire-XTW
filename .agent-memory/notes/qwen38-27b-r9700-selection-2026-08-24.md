## Production notes (exploratory context)

- MTP: greedy only. MQ4 and FP8 GPU serve **Pass** after head-drop fix. MQ4 5/10 `--spec mtp`: 47.8 tok/s τ=2.40 (1.30× AR). Think×MTP 54.7 tok/s τ=2.77 (max=256).
- Thinking-on: DFlash still falls back to AR. Native MTP spec-decodes through the think span (quality + 5/10). Think-on AR 36.5 ≈ think-off 36.7.
- slots / batch backends not exercised — noslots only.
- `fp8_wmma` flag: HFP4 activation WMMA, not qt=40 FP8 weight enable (default off).

## Selection

**Pick MQ4 for production on R9700.** Quality pass on both dtypes. MQ4 5/10 AR 36.7 vs FP8 protocol-lite 20.6; MQ4 MTP 47.8 vs FP8 MTP 38.7; ~12 GB more VRAM. Thinking-on does not change the ranking. Native MTP works with thinking.

Caveats: greedy MTP only, noslots, default CLI bench prompt, FP8 is protocol-lite n=3 not 5/10, FP8 think×MTP quality untested.
